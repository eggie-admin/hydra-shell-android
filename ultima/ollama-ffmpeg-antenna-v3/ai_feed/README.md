# KAI 9000 AI Feed subsystem

Original MIT-licensed additive module for the canonical Hydra runtime.

Responsibilities:
- SQLite WAL state;
- RSS/Atom ingestion;
- FTS5 retrieval with safe query quoting;
- localhost Ollama mini chat;
- human-feedback learning candidates;
- explicit review gate;
- no autonomous training/promotion.

This module intentionally owns no shell, Git, ADB, Shizuku, APK or publishing tool.
