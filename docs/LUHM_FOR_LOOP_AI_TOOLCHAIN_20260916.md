## Purpose

FOR LOOP is the canonical bounded evidence-control cycle for the LuHm Boss workflow. It converts provider-heavy orchestration into one deterministic control plane with one user-facing Lum Boss, three bounded skills, explicit provenance, and proof-before-GREEN.

This mutation does not compile, sign, install, merge, publish, change Play tracks, expose local services, or ingest private donor material into the public repository.

## Canonical control cycle

1. LOAD: recover current Quest, private canonical source-of-truth, and existing proof.
2. ORIGIN: identify exact repo SHA, runtime state, provider state, and source provenance.
3. INGEST: accept allowlisted local files, JSON, RSS/XML evidence, CI receipts, and model manifests.
4. NORMALIZE: convert evidence to a typed JSON-compatible envelope before model use.
5. PROVENANCE: record source, ownership/license, immutable revision/hash, and `ship_allowed`.
6. LOCAL: deterministic Python first; local model reasoning only when it adds value.
7. CORROBORATE: OpenAI, Hugging Face, or Google may advise only when materially useful.
8. CRITIC: check contradictions, secrets, donor contamination, stale proof, and authority drift.
9. PROOF: bind claims to evidence refs, rollback state, and an observable result.
10. CONDITION: terminate as PROVEN, BLOCKED, CROWN_REQUIRED, or NEEDS_HUMAN. NULL means unresolved evidence and may loop only within the hard pass budget.
